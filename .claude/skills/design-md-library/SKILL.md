description: Library of ready-made DESIGN.md design systems (Stripe, Linear, Apple, Tesla, Nike, Vercel and more) to use as a reference when building a website, landing page, store or UI.

When the user names a brand look or no design system is chosen: list systems/, pick the named one or propose 2 or 3 that fit, read only those files, and use their tokens, type, spacing, radii and component rules. Adapt, never clone: no logos, brand names or proprietary fonts (swap for open alternatives). Keep the user's own brand colours and type if they exist.
